# 深入理解 AI Agent：設計原理與工程實踐（繁體中文・大字寬鬆排版）

《深入理解 AI Agent：設計原理與工程實踐》（李博杰 著）的繁體中文重新排版版本。
原書開源於 [bojieli/ai-agent-book](https://github.com/bojieli/ai-agent-book)，Apache-2.0 授權。

**成品在 [`pdf/`](pdf/)**：14 個 PDF、共 688 頁。

## 這個版本做了什麼

### 一、繁體中文

原書為簡體中文。上游倉庫已有社群繁體譯稿（`book-zhtw/`，譯者 [@tigercosmos](https://github.com/tigercosmos)），
品質良好且與簡體原版同步（各章標題數完全一致、字數差距在 1% 以內），因此以它為底本，
而非重新翻譯。

在此之上補做了一次**簡繁「一對多」漏轉字**的校正 —— 這類字在繁體中同樣存在，
不能整批轉換，只能逐一看語境。共修正 13 處：

| 修正 | 處數 | 說明 |
| --- | :--: | --- |
| 里 → 裡 | 9 | 只改當方位助詞的「里」（如「上下文里」→「上下文裡」）；「里程碑」「新德里」保持不動 |
| 占用 → 佔用 | 1 | 表「占據」義時台灣用「佔」；「拜占庭」保持不動 |
| 采用 → 採用 | 1 | 動詞用「採」 |
| 采取 → 採取 | 1 | 同上 |
| 團伙 → 團夥 | 1 | 台灣用「夥」 |

校正後全書仍有 86 個「一對多」字元，但逐字檢查後確認**全部都是正確的繁體用法**：
里程碑、拜占庭、上游／下游、批准、干預、干擾、划算。規則與例外清單見
[`tools/fix-zhtw.mjs`](tools/fix-zhtw.mjs)。

### 二、重新排版

原版 PDF 正文約 10.5pt、單頁字數偏高。本版的設定：

| 項目 | 本版 | 原版（約） |
| --- | --- | --- |
| 正文字級 | **14pt** | 10.5pt |
| 行高 | **1.9** | 1.5 |
| 每行字數 | 約 35 個中文字 | 約 45 |
| 每頁字數 | 約 750–1100 字 | 明顯更多 |
| 邊界 | 上 20mm／下 18mm／左右各 18mm | 較窄 |
| 表格字級 | 11.5pt（不小於此下限） | 更小 |

分頁規則也一併處理，避免「一頁塞太多」之外的另一類問題：

- 標題不落單 —— 標題與其後文字不分頁（`break-after: avoid`）
- 表格「列」不被切成兩半，跨頁時表頭自動重複
- 圖片與圖說整塊不分頁，並限高 185mm，不會被裁掉或獨佔整頁
- 25 行以內的程式碼區塊不分頁；更長的才允許跨頁（否則會擠出空白頁）
- 程式碼長行折行顯示，右側不會被裁掉
- 每章獨立成檔，章首有封面頁與**本章目錄**，頁尾有「章名 · 頁碼」
- 全書 191 處註腳正確轉為上標編號，並彙整到各章末的「註釋」

正文放棄左右對齊（justify）。本書中英夾雜密集，長英文詞無法斷行時
justify 會把中文字距拉開成「所 有 事 情 的 集 合」，反而更難讀。

排版後全書 688 頁，經 `npm run audit` 確認**無空白頁**。

## 重新產生

需要 Node.js、Chromium，以及有 Bold 字面的 CJK 字型（本版用 `fonts-noto-cjk`）。

```bash
npm install
npm run build    # 產生 html/ 與 pdf/
npm run audit    # 檢查頁數與空白頁
```

想調整字級只要改 [`tools/build.mjs`](tools/build.mjs) 裡 `body { font-size }` 一行，
其餘尺寸多以此為基準等比呈現。
