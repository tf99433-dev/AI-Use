這份檔案是什麼

這是《深入理解 AI Agent：設計原理與工程實踐》（李博杰 著）的繁體中文大字排版版。

原書以簡體中文寫成，開源於 github.com/bojieli/ai-agent-book，採用 Apache-2.0 授權。本版本做了兩件事：

  1. 繁體中文：以上游社群繁體譯稿（譯者 @tigercosmos）為底本，再逐字檢查簡繁「一對多」漏轉字並修正用字（例如方位助詞「里」改為「裡」、「占用」改為「佔用」、「采用」改為「採用」）。
  2. 重新排版：原版 PDF 單頁字數偏高、字級約 10.5pt，長時間閱讀吃力。本版把正文放大到 14pt、行高 1.9，每行約 35 個中文字、每頁約 27 行；並確保標題不落單、表格列不跨頁、圖片不被切成兩半。每章獨立成一個 PDF，章首附本章目錄。

全書架構

全書圍繞核心公式 Agent = LLM + 上下文 + 工具 展開，十章層層遞進：

章 主題 一句話核心
1 Agent 基礎知識 Agent = LLM + 上下文 + 工具；Harness 工程才是競爭力
2 上下文工程 上下文決定能力上限：KV Cache、提示工程、Agent Skills、上下文壓縮
3 使用者記憶和知識庫 跨會話記住使用者、接入外部知識：使用者記憶、RAG、結構化索引、知識圖譜
4 工具 工具是 Agent 的雙手：MCP 協議、感知／執行／協作三類工具、事件驅動非同步 Agent、主動工具發現
5 Coding Agent 與程式碼生成 程式碼是「能創造新工具的工具」，生產級 Coding Agent 全景
6 Agent 的評估 把表現變成可比較訊號：評估環境、指標、統計顯著性、評估驅動選型
7 模型後訓練 預訓練／SFT／RL 三階段：何時選 SFT、何時選 RL，工具呼叫內化、樣本效率
8 Agent 的自我進化 不改權重也能成長：經驗學習、從工具使用者到創造者
9 多模態與即時互動 從文字擴充到語音、GUI、物理世界：語音三典範、Computer Use、機器人
10 多 Agent 協作 群體智慧高於個體：協作框架、上下文共享／隔離、湧現的「Agent 社會」

除十章正文外，另有引言、後記與習題參考答案。

想自己重新產生檔案

排版參數都寫在 tools/build.mjs 開頭的 CSS 裡（字級、行高、邊界、分頁規則）。改完執行：

npm install
npm run build

若只想調字級，改 body { font-size } 一行即可；其餘尺寸多以此為基準等比呈現。
